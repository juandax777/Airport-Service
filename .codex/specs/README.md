# Especificaciones

Las propuestas de cambio deben poder rastrearse a `docs/requisitos.md` o `docs/historias-de-usuario.md`. Usa la plantilla `spec-template.md` cuando el trabajo requiera aprobación de diseño, abarque varios servicios o cambie un contrato.

No crees una especificación para cada arreglo pequeño. Para decisiones de alcance pendientes, enlaza la observación existente en los documentos del proyecto y formula una pregunta concreta.
