# Guía de agentes de Airport Service

Esta carpeta adapta la organización multiagente de [`.opencode` en nexo-multiagentes](https://github.com/pivelcode/nexo-multiagentes/tree/main/.opencode) a **Sistema de Itinerarios Personales**. Conserva sus cinco áreas —`agents`, `context`, `orchestration`, `roles` y `specs`— con instrucciones centradas en este repositorio.

`AGENTS.md` en la raíz es el punto de entrada que Codex carga al trabajar. Los documentos de `.codex` complementan esas reglas con el contexto del proyecto y flujos de colaboración.

## Mapa

- `context/`: alcance, arquitectura, stack y restricciones.
- `agents/`: perfiles de especialistas por tipo de trabajo.
- `roles/`: responsabilidades y límites para las revisiones.
- `orchestration/`: ciclo de trabajo, comandos y estado inicial.
- `specs/`: guía y plantilla para definir cambios trazables.
